# Offline Wheel notices

The original Wheel archives remain byte-for-byte unchanged. Their embedded
license files and METADATA notices continue to apply. The additional files here
preserve upstream notices missing from several native Wheel archives:

| Library | Upstream source / version | Notice |
|---|---|---|
| Boost | boostorg/boost, boost-1.89.0 | [Boost](boost.txt) |
| TinyXML2 | leethomason/tinyxml2, 11.0.0 | [TinyXML2 11](tinyxml2-11.txt) |
| TinyXML2 compatibility library | leethomason/tinyxml2, 9.0.0 | [TinyXML2 9](tinyxml2-9.txt) |
| urdfdom | ros/urdfdom, 4.0.0 | [urdfdom](urdfdom.txt) |
| Assimp | assimp/assimp, v6.0.5 | [Assimp](assimp.txt) |
| OctoMap | OctoMap/octomap, v1.10.0 | [OctoMap](octomap.txt) |
| console_bridge | ros/console_bridge, 1.0.2 | [console_bridge](console-bridge.txt) |

These notices supplement, rather than replace, each dependency's distribution
terms. First-party AbilityFramework and Ability SDK/scaffold Wheels are excluded
from this source snapshot: build them from the quick-start manifest's source tags.
